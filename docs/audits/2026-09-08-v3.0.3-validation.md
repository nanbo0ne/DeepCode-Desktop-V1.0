### 保留实现的安全回归

以下来自静态审查，随后按明确分工修复；不代表新增 native 复现，行号可能变化：

- `desktop/computeruse/service.go` 生命周期问题已做 service 层修复并通过假后端测试：Start/Resume 的 hooks/overlay/观察移出 lifecycle 长锁；`nativeCalls/nativeDone` 跟踪 setup、Observe 和 Execute。停止先取消/释键，再有界等待；native 忽略取消时保留 `Stopping` 占用，不允许新 owner，实际退出后重试 Stop 才能完成清理。观察与启动/恢复的晚到收尾均受 session、epoch、generation 检查。重复 Execute 不再排在阻塞输入之后等待。
- `desktop/computeruse/backend_windows.go`：取消后的焦点/保护复查、`releaseUnicode` 失败保留、错误接口转发以及 DPI 物理上下文 5 次复查已通过；这些结果仍不等于前台真实输入或系统 DPI 真机验收。
- service 已接入可选 `ReleaseInjectedInputError() error`，旧后端兼容 void fallback。Stop/Pause/Complete/动作清理失败保持 `Stopping` 并返回错误，Stop 可再次尝试释放；终态仅在 native 调用退出、释键和安全钩子清理成功后发布。错误接口转发已通过定向回归，但不替代第五次真实测试。

此前定向结果：16 项 service/fake native 阻塞、取消、占用、恢复及旧观察回归共 3 轮通过（18.672s）；8 项 desktop 假模型控制循环、错误完成、升级恢复、provider 取消及准入回归共 20 轮通过（0.824s）。其余修复与复测见上表。以上为保留实现的回归记录，不能证明新的全平台禁用或恢复后的真机链路已通过。

更新准入门已覆盖登记的 controller、电脑控制、sidechat、broker/运行时队列、定时 tick 和记忆/欢迎建议/自动标题执行；未宣称原子覆盖本地模型下载/外部推理、settings 保存/探测本身、Bot 租约外前后处理、未登记后台子进程及其他进程。此为原有更新准入边界，不能替代电脑操控禁用门槛。
