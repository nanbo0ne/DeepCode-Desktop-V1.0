## 本轮额外修复

- Wails 默认 macOS plist 未转义产品全称的 `&`。改用受版本控制的 XML 安全模板；真实坏 DMG 已被新门禁拒绝。
- DMG 使用全新暂存路径，构建错误不再被忽略；挂载后检查版本、执行权限、双架构、图标、Applications 链接和代码签名，并与当次已签名二进制逐字节比较。
- 发布 DMG 只接受 `darwin/universal`，防止单架构包误分发给另一个架构。
- macOS 最低版本改为 12，与 [Go 工具链要求](https://go.dev/doc/go1.25#darwin)一致；Mac/Linux 窗口标题不再带 for Windows。
- 发布摘要脚本兼容 macOS `shasum` 和 Windows binary checksum 格式。Release 中英文链接改为完整地址，应用内更新说明也能打开。
