## 下载调查

完整记录见 [源站/公网测速](2026-09-08-download-diagnosis.md) 与 [实际下载器探测](2026-09-08-nextpatch-evidence/live-updater-probe.md)。

- Mac 本机正确源站读取很快、支持 Range；局域网 8089 端口仅回环绑定。8088 返回另一站点 HTML，不能用作更新源。
- 一次 4 MiB 公网抽样：Mac 源约 577,617 B/s（564 KiB/s），首字节约 2.02s；同批 GitHub 20s 只收到约 99 KB。Cloudflare 缓存命中不能保证客户端吞吐。
- 随后的 Orca 下载器短段探测：Mac 174,810 B/s，GitHub 466,381 B/s，均收到 206 并正确发送 Range。其首 1 MiB 是人为创建的零填充前缀，实际网络各读取约 1 MiB；这是续传协议和取消测试，**不是完整包下载或正确内容续传证明**。
- 更新器完整性、错误 Range、切源和摘要拒绝另有本地 HTTP 单测；候选包签名在下一节独立验证。实际 UI 也验证了取消、选择 GitHub、重试三步调用及速度/ETA 呈现。
- 各批来源排序会变化。没有证据支持服务器明确限速，未擅改 Caddy、Cloudflare 或 LAN 暴露范围，也不承诺固定下载速度。
