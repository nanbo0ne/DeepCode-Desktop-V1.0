## 界面

Modern 保留四项菜单和单行 Composer，降低用户消息阴影与色块，把缓存命中、累计 token 和压缩阈值放到统计详情。Classic 保留原布局、蓝白配色和原控件分布，只修正已复现的控件重叠。

未把浏览器预览当成原生 DPI 验证，也没有声称 Classic 与 V2 全页像素完全一致。小于原生最小窗口 760px 的 Classic 压力场景单列，不以重做 Classic 来消除不受支持窗口的所有溢出。

## 验证与剩余边界

真实安装升级、完整大模型下载、跨显示器 DPI 和安全桌面测试未执行；没有操作真实用户配置。

## 第二轮发现

- 设置操作成功但刷新失败时，重试只重新读取，不再次删除或安装。故障注入验证调用次数不增加。
- 消息提交失败保留文本和附件；提交等待期间继续输入、添加附件或切换会话，不清空新的草稿。真实 DOM 拒绝/重试及两种异步竞争场景通过。
- 下载恢复加入 worker 交接，防止暂停后的旧线程和新线程同时写同一 `.part`。
- Computer Use 增加会话范围的取消、全局观察代际、失败后释放输入和独立结果核验；独立审查继续补 Windows token、输入释放、UIA 失败和钩子线程退出路径。
- OpenAI-compatible 和 Anthropic 流在消费者取消后都能退出，所有 chunk 发送检查 context；取消不触发重连。
- 跨会话审批的拒绝不能继续走旧 Controller 回退路径，已追加调用链审查，不能只验证 broker 方法。
- 打包配置去掉机器专属 npm 缓存路径。旧便携 ZIP 只有主程序，本地新包将带 CodeGraph；历史损坏的 `github-release-final` 暂存副本不作为输入，也未删除。
- MCP 安装计划在审批前调用同一配置校验，不把不支持的 SSE 宣称为可安装；只读历史发送明确拒绝，保留草稿。

## 已完成的界面验证

- Modern/Classic、中英文、空会话/运行/演示共 78 场景；支持的 760px 及以上窗口无控件重叠或截断，未捕获页面异常。
- 80 个额外组合覆盖 1920/1366/1024/820/760px、右栏开/关及浏览器 DPR 1/1.25/1.5/2，无布局失败。浏览器 DPR 不等于真实 Windows 跨屏 DPI 验收。
- 全屏 Modern 欢迎区水平居中偏差 0px，滚动区距主区右沿 0px，操作区右侧边框内缩 1px。
- 已逐张检查最终 Modern/Classic 渲染图，Classic 保留旧蓝白布局；没有批量读取用户旧截图。
- 低于原生 760px 最小宽度的压力测试仍有 Classic 控件重叠，Modern 的部分演示内容在 320px/380px 截断。未为此改变 Classic 布局，作为不支持宽度的残余记录。

## 发布前仍需验证

1. 隔离 Windows VM 内全新安装、V2/V3 升级和卸载，验证快捷方式、注册表、用户数据和模型保留行为。
2. 真实 UIA、键鼠、全局 Esc、UAC/锁屏保护、多显示器及跨屏 DPI。当前通过的是假后端、合成 COM 和浏览器 DPR，不代替真实桌面验收。
3. 完整模型下载、真实显存预算及加载；本轮只验证固定远端元数据与受控 HTTP 下载状态机。
4. `-race`：当前 CGO 关闭且缺少 gcc，没有取得竞态检测通过结果。macOS/Linux 仅配置锁相关测试包完成交叉编译，没有执行对应平台的整机 UI/安装验收。
5. 回答风格仍受模型影响：真实 Flash 测试已消除无关工具，但仍有多余段落和追问；不使用硬性截断掩盖它。更多真实会话需继续观察。
6. 本地打包使用 Node 24.19.0 和同版本发行许可证；正式发布应从明确的官方发行包重新固定二进制/许可证来源，并补齐 CodeGraph 构建脚本下载摘要校验。现有本地文件不等于已完成供应链认证。
7. 前端仍有 bundle 体积提示，Wails 仍输出 `time.Time` 绑定提示；TypeScript/生产构建成功。它们保留为后续维护项，不记作已消除。
